Phase 2: Network Hardening & Perimeter Defense

Isolate database subnets, restrict public ports, and deploy WAF protections.

3 Checks
#sc-4

Zero Public SSH / RDP Access (Port 22/3389 Disabled)

Confirm no EC2/VM instances expose port 22 or 3389 to 0.0.0.0/0. Enforce AWS Systems Manager Session Manager or Teleport.

CLI Command / Verification 
aws ec2 describe-security-groups --filters "Name=ip-permission.from-port,Values=22" --query "SecurityGroups[?IpPermissions[?contains(IpRanges[].CidrIp, '0.0.0.0/0')]].GroupId"
#sc-5

Isolate Database Subnets into Private-Only VPCs

Confirm all database instances (RDS, Redis, Mongo) reside in non-routable private subnets without public IP attachments.

CLI Command / Verification 
aws rds describe-db-instances --query "DBInstances[*].[DBInstanceIdentifier, PubliclyAccessible]"
#sc-6

WAF & DDoS Mitigation Active on All Public Ingresses

CLI Command / Verification 
aws wafv2 list-web-acls --scope CLOUDFRONT
